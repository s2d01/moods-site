## Optional website analytics

- GA4 property: MOODS — Website, under the existing S2D01 account.
- Web stream: MOODS landing page, ID 16191419550.
- Measurement ID: G-L6DPMYNZL8.
- `analytics.js` loads Google Analytics only after explicit opt-in on the production hostname.
- Analytics preferences in the footer lets visitors reject or withdraw consent. Preferences expire after 180 days.
- Advertising consent remains denied; Google signals and ad personalization are disabled.
- Enhanced measurement is disabled in the stream. The website sends page views and the fixed events `early_access_click`, `youtube_click`, and `discord_click`.
- No form values are read by the analytics code. Early Access clicks are interest signals, not confirmed subscriptions; Formspree is the source for confirmed submissions.
- Page URL query strings/fragments are excluded and referrers are reduced to their origin.
- Analytics is website-only; this does not add telemetry to the MOODS macOS application.
